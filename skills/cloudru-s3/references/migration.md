# Миграция

Сверь пулы, эндпоинты и возможности через pools/capabilities. Регион SigV4 равен выбранному пулу; адресация задаётся профилем. Передавай данные потоково, через presigned URL или multipart. Copy работает в пределах эндпоинта. Сверяй размеры и контрольные суммы до удаления источника. Возможности целевого облака проверяй по документации: https://cloud.ru/docs/s3e/ug/topics/api__getting-started https://cloud.ru/docs/s3e/ug/topics/api__methods https://cloud.ru/docs/s3e/ug/topics/api__headers-request https://cloud.ru/docs/s3e/ug/topics/api__aws-sig-v4 https://cloud.ru/docs/s3e/ug/topics/concepts__storage-class https://cloud.ru/docs/s3e/ug/topics/overview__limitations https://cloud.ru/docs/s3e/ug/topics/api__response-codes https://cloud.ru/documents/tariffs/evolution/object-storage.
