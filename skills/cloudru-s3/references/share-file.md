# Обмен файлом

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше 604800 секунд. Ограничение профиля может требовать живой проверки: Evolution Object Storage, до 7 дней. Защитные условия записи/удаления не подтверждены; SINGLE не Multi-AZ. Нужна живая проверка.. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
